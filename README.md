# Kurt Dhylan Moto Shop Inventory

Android .NET MAUI inventory app.

## Features
- Products: name, brand, model, price, stocks
- Services/labor: name and price
- Search products
- Search services
- Dashboard counts
- Low-stock count
- Offline local JSON storage
- Racing black/red UI
- GitHub Actions APK build

## GitHub
Upload the CONTENTS of this folder to the ROOT of your repository.
The `.csproj` must be visible beside `MainPage.xaml`, not inside another nested project folder.

Then open Actions and run **Build Kurt Dhylan Moto Shop Inventory APK**.
